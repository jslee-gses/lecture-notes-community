# 강의 뷰어·공개 목록·영어 번역 확장 설계

작성일: 2026-10-09

## 목적과 승인된 범위

Codex 플러그인 사용자는 한국어 또는 영어 YouTube 강의 URL을 처리하고, 시점이 연결된 목차·요약노트·용어집·전사를 웹에서 본다. 상세 화면은 흰 배경의 학습 작업 공간으로 바꾼다. 데스크톱에서는 영상과 전사를 왼쪽에, 목차·강의 요약·용어집 탭을 오른쪽에 둔다. 영상 아래 전사만 내부 스크롤하며 영상을 계속 볼 수 있고, 전사 검색어는 일치한 문자 범위가 강조된다. 모바일에서는 영상, 전사, 탭 순서로 배치한다.

서버 첫 페이지 `/`는 공개 목록이다. 계정 없이 모든 방문자가 목록을 열어 강의를 선택할 수 있다. 목록에는 **업데이트된 플러그인이 공개 업로드를 명시한 신규 결과만** 표시한다. 이전에 업로드된 결과와 이전 플러그인의 신규 업로드는 기존처럼 공유 링크를 가진 사람만 접근한다. 90일 보관·자동 삭제 정책은 공개 여부와 무관하게 유지한다. 목록은 처리 중인 로컬 작업을 표시하지 않고, 서버 업로드가 완료된 강의만 표시한다.

영어 영상은 사람이 제공한 영어 자막을 우선 사용하고, 없으면 영어 자동 자막을 사용한다. 영어 원문과 시점별 한국어 번역을 함께 저장·표시한다. 목차·요약노트·용어집은 한국어로 작성한다. 한국어 영상의 기존 결과는 계속 열린다. 영상·오디오 파일 다운로드, 별도 음성 인식, 외부 번역 API 키, 웹에서 URL을 제출해 처리를 시작하는 기능은 이 범위에 넣지 않는다. 최대 영상 길이는 기존과 같이 3시간이다.

완료 기준은 다음과 같다.

- 상세 화면의 `링크를 아는 사람과 공유`, `KOREAN LECTURE · AUTO CAPTIONS`, `강의의 흐름, 핵심 내용, 용어를 원본 영상의 시점과 함께 살펴보세요.` 문구와 상단·하단 `LECTURE / NOTES` 표시는 제거된다. 흰 배경, 좌측 영상·전사, 우측 세 탭이 데스크톱과 모바일에서 작동한다.
- 전사를 스크롤하는 동안 영상 위치가 변하지 않으며, 전사 검색은 결과 수·일치 부분 강조·빈 결과를 정확히 보여준다. 시간 버튼은 원본 영상을 해당 시점으로 이동시킨다.
- `/`에서 공개로 지정된 활성 강의를 최신순으로 선택할 수 있다. 기존 강의, 이전 플러그인의 업로드, 만료된 강의는 목록에 나타나지 않는다.
- 영어 영상은 자막 출처를 명시하고 영어 문장과 한국어 번역을 같은 구간에 표시한다. 한국어 목차·요약·용어집의 시점은 영어 원문 구간을 근거로 한다.
- 기존 한국어 JSON 1.0, 공유 URL, 업로드 재시도, 사용량 제한과 만료 동작이 유지된다.

## 채택한 접근과 작업 순서

기존 FastAPI·Jinja 서버 렌더링과 작은 JavaScript를 유지한다. 공개 목록은 같은 PostgreSQL에 저장된 업로드를 조회한다. 별도 SPA와 프런트엔드 배포는 만들지 않는다. 브라우저 로컬 저장소 목록은 모든 방문자가 같은 결과를 봐야 하는 요구를 충족하지 않는다.

작업은 두 릴리스 단계로 나눈다. 첫 단계는 상세 화면, 접근 가능한 탭과 전사 검색, 공개 목록, 공개 업로드 신호 및 마이그레이션이다. 둘째 단계는 영어 자막 선택·정제·번역, 이중 언어 JSON 계약과 화면 표시다. 각 단계는 구현과 로컬·CI 검증 결과를 사용자에게 제시하고 배포 승인을 받은 뒤 Railway와 플러그인 릴리스를 갱신한다. 배포 후 실제 페이지도 검증한다. 서버는 이전 클라이언트가 계속 사용할 수 있도록 호환 가능한 변경을 먼저 준비한다.

## 상세 화면

### 구조와 반응형 동작

`server/app/templates/lecture.html`을 상세 화면의 한 진입점으로 유지한다. 상단에는 강의 목록으로 돌아가는 링크와 강의 제목·길이 등 필요한 메타데이터만 둔다. 위에 명시한 세 문구와 `LECTURE / NOTES` 워드마크는 삭제한다. 전체 페이지 배경은 흰색이고 카드·패널은 구분선으로 나눈다.

데스크톱에서는 왼쪽이 더 넓은 2열 레이아웃을 쓴다. 왼쪽 위에 16:9 YouTube 플레이어와 대체 YouTube 열기 링크를 두고, 그 아래 전사 검색·전사 목록을 둔다. 왼쪽 열은 화면 높이에 맞춰 배치하고 전사 목록에 자체 `overflow-y: auto`를 적용한다. 전사 목록을 휠·터치·키보드로 스크롤해도 플레이어는 같은 화면 위치에 남는다. 오른쪽 위에는 `목차`, `강의 요약`, `용어집` 탭을 두고 선택된 패널의 내용만 표시한다. 오른쪽 내용도 길면 해당 패널 안에서 스크롤한다. 시간 버튼을 누르면 영상 시점을 바꾸며 페이지를 강제로 스크롤하지 않는다. YouTube 임베드가 실패하면 기존 외부 YouTube 시점 링크를 제공한다.

폭이 좁은 화면에서는 영상 → 전사 → 탭 순서의 단일 열로 바꾼다. 전사 목록은 모바일에서도 정해진 높이 안에서 자체 스크롤하므로 전사를 읽는 동안 영상이 위에 남는다. 세로 공간이 매우 짧은 화면에서는 화면 전체 스크롤을 허용해 컨트롤이 가려지지 않게 한다.

탭은 `tablist`·`tab`·`tabpanel`, 선택 상태, 포커스 표시 및 키보드 화살표·Home·End 탐색을 제공한다. 탭 전환은 페이지 이동이나 플레이어 재생 상태 초기화를 일으키지 않는다. 목차의 메인·세부 항목, 요약 핵심 내용, 용어집 시점 버튼은 기존 원본 시점 이동 기능을 유지한다.

전사 검색은 현재처럼 불일치 구간을 숨기되 일치한 문자열을 `<mark>`로 표시한다. 검색어 삭제 시 모든 구간과 원래 텍스트를 복원한다. 대소문자를 구분하지 않는 영어 검색과 한국어 검색을 지원하고, 검색 결과 수 및 결과 없음 상태를 알린다. 사용자 텍스트는 HTML 문자열로 직접 조합하지 않고 텍스트 노드에서 강조 요소를 만들어 스크립트 삽입을 막는다. 둘째 단계의 영어 결과에서는 원문과 번역 양쪽을 검색하고 각각의 일치 부분을 표시한다.

### 뷰어 데이터 경계

서버는 현재처럼 검증된 JSON을 Jinja에 전달하고 Jinja 이스케이프를 유지한다. 영상 ID는 기존 11자 검사를 거쳐 임베드와 대체 링크를 구성한다. 브라우저는 서버가 표시한 전사 텍스트와 시점만 사용하며, 외부 자막을 다시 가져오지 않는다. 기존 `/api/lectures/{share_token}`과 `/data` 주소는 유지한다.

## 공개 목록과 업로드 호환성

`server/migrations/002_public_listing.sql`은 `lectures.is_listed BOOLEAN NOT NULL DEFAULT FALSE`와 공개 목록 조회용 인덱스를 추가한다. 마이그레이션 실행기는 번호순 SQL 파일을 재실행 가능하게 적용한다. 기본값이 `FALSE`이므로 과거 행은 자동으로 공개되지 않는다.

업데이트된 플러그인은 새 업로드에 `X-Lecture-Listing: public`을 보낸다. 서버는 정확한 `public` 신호가 있는 **신규 `run_id` 삽입**에만 `is_listed=TRUE`를 저장한다. 이전 플러그인처럼 헤더가 없으면 비공개 링크로 저장한다. 다른 헤더 값은 422로 거절한다. 동일 `run_id`의 동일 본문 재시도는 기존 공유 URL과 기존 공개 상태를 그대로 반환하고 사용량 제한도 추가로 소비하지 않는다. 헤더만 바꾸어 기존 결과를 공개로 승격하거나 비공개로 바꾸지 않는다. 바뀐 본문은 기존처럼 409다. 공개 신호는 결과 JSON의 내용 해시와 분리하여 이전 클라이언트의 JSON 계약을 깨지 않는다.

업데이트된 플러그인의 설명과 업로드 결과는 강의 제목과 내용이 공개 목록에 표시된다는 사실을 명확히 알린다. 별도 로그인이나 비밀 API 키는 요구하지 않는다. 사용량 제한, 최대 10 MiB 본문, 임의 공유 토큰, HTML 이스케이프는 그대로 적용한다.

`GET /`은 활성(`expires_at > now`)이며 `is_listed=TRUE`인 강의만 읽어 제목·길이·업로드 시각을 최신순으로 20건씩 서버 렌더링한다. 같은 시각은 `run_id`로 순서를 고정한다. 각 항목은 기존 상세 공유 URL로 연결한다. 비어 있으면 공개된 강의가 없다는 안내를 보여준다. 목록 조회는 큰 JSONB 본문을 통째로 읽지 않고 필요한 메타데이터만 선택한다. 기존 `GET /api/lectures`의 비공개 API 동작은 변경하지 않는다. 만료된 행은 정기 삭제 전에도 목록 조회와 상세 조회에서 제외한다.

모든 방문자가 `/`을 열면 공개 강의를 볼 수 있다. 검색 엔진 색인 여부는 이 단계에서 확대하지 않고 상세 페이지의 기존 `noindex` 설정을 유지한다. 목록 공개는 URL을 아는 방문자 범위에 제한되지 않는다는 점을 플러그인·README에 명시한다.

## 영어 자막·번역 처리와 JSON 계약

기존 한국어 `schema_version: "1.0"` 문서는 그대로 읽고 검증한다. 영어 문서는 `schema_version: "2.0"`을 사용한다. 영어 문서의 `lecture.caption_language`는 `en`, `caption_source`는 `manual` 또는 `auto`, `translation_language`는 `ko`다. 나머지 목차·요약·용어집의 구조와 1부터 시작하는 구간 참조는 기존과 같다. 각 영어 `segments[]`는 원문 언어의 정제 전사 `text`와 비어 있지 않은 `translation_ko`를 가진다. 두 텍스트는 같은 `idx`, `start_sec`, `end_sec`에 묶이며 구간을 빠뜨리거나 합치지 않는다. 원시 자막은 로컬 실행 디렉터리에 보존하고 업로드하지 않는다. 영어 문서에서도 JSON 전체가 한 파일로 업로드된다.

플러그인은 메타데이터와 자막 트랙을 확인해 실제 영어 원본 트랙을 선택한다. 사람이 제공한 영어 자막이 있으면 우선 사용하고, 없으면 영어 자동 자막을 사용한다. YouTube가 다른 언어에서 자동 번역한 영어 트랙을 원본 영어 자막으로 간주하지 않는다. 영상의 원래 언어 또는 트랙 출처를 신뢰성 있게 확인할 수 없으면 임의 선택하지 않고 사용자에게 알린다. 자막이 없거나 지원되는 형식으로 읽을 수 없으면 이유를 알리고 중단한다. 가능한 자막 형식은 JSON3를 우선 정규화하고, 제공 자막에 JSON3가 없을 때는 VTT를 파싱해 같은 구간 구조로 만든다. 영상 파일과 오디오는 내려받지 않는다.

영어 자막에도 기존의 전체 강의 선행 읽기 절차를 적용한다. 모든 청크를 읽어 흐름·반복 용어·오인식 의심 표현을 기록한 뒤, 자동 자막의 확실한 오류만 원문 근거에 따라 보수적으로 교정한다. 제공 자막도 내용 변경 없이 필요한 최소한의 표기 정리만 한다. 그다음 각 구간에 대응하는 한국어 번역을 작성하되 앞뒤 문맥과 강의 전체 용어 표기를 일관되게 사용한다. `translations/<chunk>.json`은 각 `segment_idx`에 번역 한 개를 기록하고 조립 단계에서 모든 구간의 정확한 1:1 대응을 검증한다. 불확실한 고유명사·전문 용어는 영어 표기를 유지하고 사용 결과에서 불확실성을 알린다. 목차·요약·용어집의 한국어 설명은 교정된 영어 전사와 대응 번역을 모두 확인하고 실제 구간 번호를 근거로 작성한다.

클라이언트와 서버는 1.0과 2.0을 명시적으로 구분해 검증한다. 2.0은 번역 누락·빈 번역·잘못된 자막 출처·구간 시점 불일치·목차 범위 누락을 업로드 전에 거절한다. 서버도 같은 계약을 다시 확인한다. 기존 1.0 문서와 URL을 2.0으로 자동 변환하거나 재업로드하지 않는다. 뷰어는 1.0에서 기존 한국어 전사만, 2.0에서 영어 원문과 한국어 번역을 함께 보여준다.

## 오류 처리와 검증

자막 수집, 전체 맥락 읽기, 교정, 번역, JSON 조립, 업로드는 현재와 같이 재시작 가능한 로컬 단계로 유지한다. 실패하면 원본 자막과 완료된 중간 파일을 보존하고 실패한 단계를 알려준다. 자막 부재·불명확한 원어 트랙·지원하지 않는 자막 형식은 빈 결과를 업로드하지 않는다. 업로드의 409·413·422·429 응답 처리와 같은 파일 재시도 규칙은 유지한다.

첫 단계의 자동 검증은 PostgreSQL 마이그레이션과 과거 행 비공개 유지, 신규 공개 플래그, 재시도 시 공개 상태 불변, 목록 정렬·페이지 경계·만료 제외, HTML 이스케이프를 포함한다. 브라우저 검증은 데스크톱·모바일 배치, 탭의 마우스·키보드 조작, 시간 이동, 전사 내부 스크롤 중 플레이어 위치, 검색 강조·초기화·결과 없음, 긴 강의 구간 수를 확인한다.

둘째 단계의 자동 검증은 제공 영어 자막 우선 선택과 자동 자막 대체, 불명확한 원어 트랙·자막 부재 실패, JSON3/VTT 정규화, 전체 청크와 번역 구간의 완전한 대응, 영어 2.0 계약 및 한국어 1.0 호환성을 포함한다. 실제 영어 공개 강의 한 편으로 자막 수집부터 번역·업로드·화면 표시까지 검증하고, 기존 한국어 강의도 다시 확인한다. GitHub CI의 Windows 도구 설치, Deno, PostgreSQL, Docker 검사는 두 단계에서 모두 통과해야 한다.

## 관련 파일과 배포

- `server/app/templates/lecture.html`, `server/app/static/lecture.css`, `lecture.js`: 상세 화면·탭·전사 검색.
- 새 목록 템플릿과 `server/app/views.py`: `/` 공개 목록 및 기존 상세 주소.
- `server/migrations/002_public_listing.sql`, `server/app/migrate.py`, `repository.py`, `main.py`: 공개 여부·조회·업로드 신호.
- `plugins/lecture-notes/scripts/captions.ts`, `cli.ts`, `assemble.ts`, `types.ts`, `schema/lecture.schema.json`: 영어 자막 선택, 번역 조립, 1.0/2.0 검증.
- `plugins/lecture-notes/skills/lecture-notes/SKILL.md`, `README.md`: 공개 목록 안내와 영어 처리 판단 절차.
- `server/tests`, `server/e2e`, `plugins/lecture-notes/tests`: 회귀·브라우저·자막·계약 검증.

각 단계는 테스트 결과와 변경 내용을 제시해 배포 승인을 받은 후 새 플러그인 버전으로 공개한다. Railway는 해당 버전의 서버 코드를 배포하고 실사용 검증을 진행한다. 이전 릴리스의 공유 URL과 설치된 구버전 플러그인의 동작을 유지한다.
