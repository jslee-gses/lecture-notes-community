# 한국어 유튜브 강의 노트 플러그인 설계

작성일: 2026-10-09

## 목적과 성공 기준

사용자는 Codex에서 YouTube 강의 URL 하나를 입력해 한국어 자막을 정제하고, 2단계 목차·강의 전체 요약노트·용어집을 얻는다. 결과는 `lecture.json` 한 파일로 로컬에 보존하고 Railway 웹 서버에 전송한다. 서버가 돌려준 공유 URL을 아는 사람은 강의 내용과 원본 영상의 해당 시점을 함께 탐색할 수 있다. 플러그인은 GitHub 공개 저장소의 마켓플레이스에서 누구나 설치할 수 있게 배포하며, 사용자는 별도 가입·API 키 없이 업로드할 수 있다.

첫 버전은 한국어 강의 최대 3시간을 대상으로 한다. 사용할 수 있는 한국어 자막이 없으면 이유를 알리고 중단한다. 음성 자동 전사, 영상 다운로드·편집·저장, 웹에서 URL을 입력해 처리를 시작하는 기능은 범위에 넣지 않는다. 기존에 설치된 `lecture-pipeline` 플러그인은 구조와 검증 아이디어를 참고하되 코드는 새로 작성한다.

완료 기준은 다음과 같다.

- Codex 플러그인 명령 한 번으로 유효한 한국어 강의를 처리하고 공유 URL을 받는다.
- 2단계 목차, 전반 요약노트, 용어집, 정제 전사의 항목은 실제 자막 구간과 시간 정보에 연결된다.
- 자막 부재, 잘못된 URL, 생성물 검증 실패, 업로드 실패가 어느 단계에서 발생했는지 알 수 있다. 업로드 실패 때는 같은 `lecture.json`으로 업로드만 재시도할 수 있다.
- 공유 URL을 아는 사람은 로그인 없이 결과를 열 수 있고, 공개 강의 목록이나 순차적인 ID로 다른 결과를 찾을 수 없다.
- GitHub 저장소를 마켓플레이스로 등록한 사용자가 플러그인을 설치해 자신의 강의를 처리할 수 있다. 설치 안내와 의존성 점검을 제공한다.
- 익명 업로드 결과는 90일 뒤 자동 삭제되고 공유 URL도 만료된다.

## 시스템 경계

### Codex 플러그인과 로컬 처리기

새 플러그인 이름은 `lecture-notes`로 한다. Codex 명령 `$lecture-notes <youtube-url>`이 스킬의 진입점이다. 첫 배포의 지원 대상은 Windows의 Codex 데스크톱이다. 플러그인은 `SKILL.md`의 판단 절차와 Deno 기반 TypeScript 스크립트의 결정적 처리 절차로 구성한다. 스크립트는 URL 검증, 자막 수집 호출, 전처리, 청크 구성, JSON 조립·검증·업로드를 맡는다. Codex 모델은 기술 용어 오인식 교정, 목차 구성, 요약노트와 용어집 작성 등 의미 판단을 맡는다. 별도 LLM API 키나 서비스 가입은 요구하지 않는다.

첫 실행 시 플러그인은 `deno.exe`와 공식 `yt-dlp.exe`의 필요한 버전을 검사하고, 없으면 배포자가 고정한 공식 릴리스에서 작업 폴더의 도구 캐시로 자동 다운로드한다. 다운로드한 파일은 플러그인에 기록한 SHA-256과 일치해야 실행한다. 관리자 권한이나 시스템 전역 설치는 사용하지 않는다. Codex가 다운로드·실행 승인을 요구하는 환경에서는 그 승인이 필요할 수 있으며, 네트워크에서 공식 릴리스에 접근하지 못하면 수동 설정을 요구하는 대신 원인을 표시한다. Deno는 로컬 스크립트 실행과 yt-dlp의 YouTube JavaScript 처리에 함께 사용한다. macOS·Linux 지원은 별도 릴리스 과제로 둔다.

`yt-dlp`로 영상 파일 없이 한국어 자막과 제목·길이·영상 ID를 로컬에서 확보한다. 한국어 자동 생성 자막을 처리 대상으로 삼고, 해당 자막을 확보하지 못하면 명확한 오류로 종료한다. 자막 수집은 서버가 아니라 Codex 실행 기기에서 수행한다. 클라우드 IP에서의 비공식 자막 접근 차단 가능성을 피하기 위한 배치이며, 로컬에서도 YouTube 접근은 실패할 수 있으므로 오류를 그대로 보고한다.

로컬 작업 디렉터리에는 원본 자막, 정규화한 시간별 문장, 전체 맥락 브리프, 판단 단계별 중간 JSON, 최종 `lecture.json`을 남긴다. 먼저 정규화한 전체 자막을 빠짐없이 훑어 강의 주제·흐름·반복 용어·표기 근거와 오인식 의심 표현을 기록한다. 3시간 강의의 전체 자막이 한 번의 모델 입력에 담기지 않으면 모든 청크를 순서대로 읽고 구간 메모를 합쳐 전체 맥락 브리프를 만든다. 그다음 각 청크의 원문, 인접 청크의 읽기 전용 문맥, 전체 맥락 브리프를 함께 보고 기술 용어를 포함한 오인식 가능성이 높은 단어를 교정한다. 교정은 해당 자막의 전후 문맥 또는 강의 안에서 확인된 표기를 근거로 하며, 확실하지 않은 후보는 원문을 유지한다. 구두점과 문장 경계도 보수적으로 고친다. 발화의 주장이나 예시를 삭제하거나 새로 쓰지 않는다. 전역 문장 번호와 원본 시간을 유지하며 실패한 청크나 단계만 다시 실행할 수 있다.

### Railway 서버와 웹

Railway에 Python 웹/API 서비스 하나와 PostgreSQL 서비스 하나를 배포한다. 웹/API는 FastAPI와 서버 렌더링 HTML, 작은 JavaScript 모듈로 구현한다. 한 서비스가 JSON 업로드 API, 공유 페이지, 정적 리소스를 제공한다. PostgreSQL에는 강의 메타데이터, `lecture.json` 본문(JSONB), 업로드 실행 ID, 공유 토큰을 저장한다. 영상 파일은 저장하지 않는다.

업로드는 HTTPS의 무계정 익명 요청이다. 공개 플러그인에 공통 비밀 토큰을 넣지 않는다. 서버는 JSON 본문을 최대 10 MiB로 제한하고, 신뢰할 수 있는 프록시가 전달한 클라이언트 IP 기준으로 1시간 3건·하루 10건, 서비스 전체 하루 200건의 업로드 상한을 적용한다. 제한값은 서버 환경변수로 조절하고 즉시 신규 업로드를 중지하는 운영 스위치를 둔다. IP는 원문 대신 서버 비밀값으로 계산한 단기 해시를 제한 집계에 사용한다. 이 제한은 남용 위험을 줄이지만 익명 공개 업로드를 완전히 보호하지는 못한다.

업로드마다 로컬에서 생성한 `run_id`를 보내고 서버는 이를 고유값으로 취급한다. 같은 파일의 재시도는 할당량 검사 전에 기존 결과를 찾아 같은 공유 URL을 돌려주고, 새 처리 실행은 새 결과로 저장한다. 공유 URL은 암호학적 난수 토큰을 사용한다. 결과는 생성 90일 후 데이터와 함께 삭제되며, 만료된 링크는 404를 반환한다. 페이지는 검색 엔진 색인을 요청하지 않으며 공개 목록 API를 제공하지 않는다. 링크를 가진 사람은 내용을 볼 수 있으므로 사용자가 URL을 전달할 때 그 범위를 결정한다. 서버는 표시할 텍스트를 이스케이프하고, 허용된 YouTube 영상 ID로만 임베드 URL을 만든다.

## 데이터 흐름과 계약

1. URL에서 영상 ID를 검증하고 한국어 자막과 메타데이터를 확보한다.
2. 시간 정보가 있는 문장으로 정규화하고 전체 자막을 훑어 강의 맥락과 반복 용어를 파악한다.
3. 전체 맥락과 전후 구간을 근거로 청크별 오인식 가능성이 높은 표현을 보수적으로 교정한다.
4. 전체 문장 범위를 빠짐없이 덮는 메인·세부 목차를 만든다. 각 목차 항목에 제목, 간단한 요약, 시작·끝 문장과 시간을 둔다.
5. 전반 요약노트를 짧은 개요와 핵심 내용 항목으로 만든다. 각 항목은 설명과 근거 문장·시점을 가진다.
6. 강의에서 실제로 설명하거나 사용하는 용어를 추려 쉬운 해설과 첫 설명 위치를 기록한다.
7. 최종 JSON을 스키마와 교차 참조 규칙으로 검증해 로컬에 저장한 뒤 서버로 업로드한다.
8. 서버가 같은 계약으로 검증하고 저장한 후 공유 URL을 반환한다.

`lecture.json`의 최상위 필드는 `schema_version`, `run_id`, `lecture`, `segments`, `outline`, `summary_note`, `glossary`로 한다. `lecture`는 영상 ID·URL·제목·길이·자막 언어와 출처·생성 시각을 가진다. `segments`는 번호·시작 초·끝 초·정제된 문장이다. `outline`은 `chapters`와 그 안의 `children`으로 정확히 두 단계이며 각 항목은 문장 범위, 시간 범위, 제목, 요약을 가진다. `summary_note`는 `overview`와 `key_points`이고 핵심 내용 항목마다 참조 문장 번호를 가진다. `glossary` 항목은 용어·해설·처음 설명된 문장 번호와 시간을 가진다. 원본 자막은 로컬에 보존하고 공유 JSON에는 넣지 않는다.

공유 계약의 기계 검증은 필수 필드·타입, 단조 증가하는 시간, 영상 길이 안의 시간, 목차의 순서·중복 없는 전체 문장 범위, 모든 참조 문장의 존재를 확인한다. 의미 검토 단계는 요약과 용어가 실제 자막에서 뒷받침되는지 점검하고 불확실한 내용은 만들지 않는다. 기계 검증만으로 의미의 진실성을 증명한다고 간주하지 않는다. 스키마 변경 시 `schema_version`을 올리고 서버가 지원하지 않는 버전은 명시적 오류로 거부한다.

API 계약은 `POST /api/lectures`(익명 JSON 업로드, 크기·빈도 제한, `run_id` 기준 재시도 안전), `GET /api/lectures/{share_token}`(공유 페이지), `GET /api/lectures/{share_token}/data`(그 페이지의 JSON 조회)로 제한한다. 업로드 응답에는 `share_url`과 만료 시각을 담는다. 수집과 콘텐츠 생성은 API에서 실행하지 않는다.

## 공유 페이지

페이지는 원본 YouTube 임베드 플레이어와 강의 제목·길이, 메인·세부 목차, 전체 요약노트, 용어집, 검색 가능한 정제 전사를 보여준다. 각 항목의 시간을 누르면 플레이어가 해당 시점으로 이동한다. 모바일 화면에서는 콘텐츠를 세로로 배치하고 목차를 접을 수 있게 한다. 임베드가 허용되지 않는 영상에는 같은 시점의 YouTube 링크를 제공한다. 별도의 영상 복사본, 사용자 계정, 공개 검색 페이지는 만들지 않는다.

## 오류와 복구

- URL 오류와 한국어 자막 부재: 수집 단계에서 영상 ID 또는 자막 상태를 알리고 종료한다.
- 중간 JSON 또는 최종 JSON 오류: 해당 단계에서 멈추고 검증 오류 위치를 출력한다. 유효한 이전 단계 산출물은 재사용한다.
- 업로드 통신 오류 또는 서버 거부: `lecture.json`을 보존하고 업로드 명령만 재실행하도록 안내한다.
- 업로드 재시도: 동일 `run_id`와 내용이면 기존 결과를 반환한다. 동일 `run_id`에 다른 내용이면 충돌 오류로 중단한다.
- 익명 업로드 제한: 크기 초과는 413, 빈도·전체 상한 초과는 429와 재시도 안내를 반환한다. 기존 결과 조회는 업로드 중지 중에도 제공한다.
- 결과 만료: 90일이 지난 데이터는 정기 정리 작업으로 제거하고 공유 페이지는 404를 반환한다.
- 서버 저장 실패: 저장 성공으로 응답하지 않으며, 플러그인이 안전하게 재시도할 수 있게 한다.

## 검증과 배포

자막 파서·청크 경계·문장 번호·스키마·참조 무결성에 대한 단위 테스트와 업로드 크기·빈도 제한·재시도·공유 URL·만료에 대한 API 테스트를 둔다. 실제 공개 한국어 강의 한 편으로 자막 확보부터 공유 페이지까지 확인하고, 3시간 분량의 자막 테스트 데이터로 분할과 조립을 검증한다. 사람이 목차·요약·용어집과 근거 시점의 정확성을 표본 검토한다.

Railway에는 웹/API 서비스와 PostgreSQL을 연결하고 `DATABASE_URL`, `PUBLIC_BASE_URL`, IP 해시용 서버 비밀값과 제한 설정을 환경변수로 지정한다. 플러그인에는 공개 업로드 서버 URL을 기본값으로 둔다. JSON 스키마 원본은 플러그인 패키지 안에 두고 서버도 같은 파일을 읽는다. Railway 서비스는 GitHub 저장소 루트를 빌드 소스로 사용하되 Dockerfile에는 서버와 스키마만 포함한다. CI 통과 후 자동 배포하도록 설정하고, 첫 배포 후 정상 업로드, 크기·빈도 제한, 공유 URL 조회, 만료, 시간 이동을 확인한다.

## GitHub 공개 배포

GitHub 공개 저장소에 플러그인·서버·설계 문서·설치 안내를 함께 둔다. 플러그인 패키지는 `plugins/lecture-notes/`에 portable `plugin.json`, `skills/lecture-notes/SKILL.md`, 첫 실행 도구 준비 스크립트, 처리 스크립트와 JSON 스키마를 포함한다. 저장소 루트의 `.agents/plugins/marketplace.json`은 그 플러그인 경로를 가리킨다. README는 GitHub 저장소를 Codex 마켓플레이스에 추가하고 플러그인을 설치하는 순서, Windows 지원 범위, 예제 URL 명령, 첫 실행의 자동 도구 준비와 가능한 실행 승인, 결과 보존 기간을 설명한다. 공개 코드의 라이선스는 MIT를 기본안으로 제안한다. 이는 설치 과정과 무관한 코드 재사용 허락이며, GitHub 공개 전에 최종 확인한다. 서버 비밀값과 실제 강의 산출물은 Git에 넣지 않는다.

첫 공개는 GitHub 저장소 마켓플레이스 설치를 대상으로 한다. 추후 OpenAI 공식 공개 플러그인 디렉터리에는 플러그인 폴더만 ZIP으로 패키징해 별도 심사 절차를 거친다. 공식 디렉터리 게시는 GitHub 공개만으로 자동으로 이뤄지지 않으며, 로컬 실행 및 실행 파일 다운로드가 심사에서 허용될지는 별도로 확인해야 한다. 플러그인에서 서버의 MCP 도구나 사용자 계정을 요구하지 않는 현재 구조를 유지한다.

## 참고한 기존 동작과 외부 제약

로컬에 설치된 `lecture-pipeline` 0.11.1의 단계별 산출물과 시간 연결 방식을 참고했다. 이 설계의 코드와 웹/API 서버는 `D:\create-skills`에 새로 작성한다. 기존 플러그인의 `notes`는 주로 명령·링크 목록이므로 이번 설계의 전반 요약노트는 별도 필드로 정의했다.

YouTube 공식 자막 API의 조회·다운로드는 OAuth 권한이 필요하다. `youtube-transcript-api` 프로젝트는 클라우드 제공자 IP 차단 가능성을 문서화한다. Railway는 PostgreSQL 연결과 공개 HTTPS 도메인을 제공하며, YouTube IFrame API는 임베드 플레이어의 시점 이동을 지원한다.
